# N64

The Nintendo 64 has no sound chip: the RSP mixes audio in microcode and the audio interface (AI) outputs 16-bit stereo
PCM. The N64 engine emulates that chain as games used it: Nintendo's audio library libultra (from the decompals/ultralib
decompilation) and the audio microcode (mupen64plus-rsp-hle, alist.c / audio.c). That means VADPCM-compressed samples,
the RSP's 4-tap resampler, libultra's exponential envelopes and equal-power panning, and Nintendo's own reverb and
chorus effects. Use it for the soft, slightly fuzzy sample sound of N64 soundtracks, with KoniSynth's samples or yours.

## What you need

Nothing extra. The six built-in sources are KoniSynth's own samples. To play your own sound, load it in the Sample panel;
KoniSynth includes no game samples.

## Controls

Three sections on one row: **N64** (source) -> **N64 Envelope** -> **N64 Effect**.

### N64

| Control | What it does | Range / default |
|---|---|---|
| Source (header menu) | KoniSynth's samples (Square, Saw, Sine: 32-sample loops; Strings, Choir: 3-voice loops; Bass), made at the chosen sample rate, or User Sample (Sample panel: Start, Length, Loop, Root). | Square / Saw / Sine / Strings / Choir / Bass / User Sample; Strings |
| VADPCM | Store the samples as VADPCM (4 bits per sample, 16-sample frames, order-2 predictor), the N64 compression with its own grit. Off: raw 16-bit samples, for comparison. | on |
| Src Rate | Rate of the sample. Games stored most samples at low rates to save cartridge space: the dull, fuzzy N64 sound. | 8 / 11 / 16 / 22 / 32 kHz; 22 kHz |
| Out Rate | Output rate of the audio interface (games used 22.05, 32 or 44.1 kHz). | 22.05 / 32 / 44.1 kHz; 32 kHz |
| Volume | Channel volume; velocity scales it when Velocity is on. | 0-127; 100 |
| Pan | Channel pan (0 = left, 64 = center, 127 = right), with libultra's equal-power table. | 0-127; 64 |
| Spread | Spreads successive notes to opposite sides. | 0-100 %; 0 % |

### N64 Envelope

| Control | What it does | Range / default |
|---|---|---|
| Velocity | Key velocity scales the voice volume (KoniSynth's driver). | on |
| Attack | Time to reach A Vol (exponential ramp, as the console's mixer). | 0-5000 ms; 5 ms |
| Decay | Time to go from A Vol to D Vol, which then holds while the key is down. | 0-5000 ms; 0 ms |
| Release | Time to fade out after the key is released. | 0-5000 ms; 200 ms |
| A Vol | Level reached at the end of the attack. | 0-127; 127 |
| D Vol | Level held after the decay. | 0-127; 127 |

### N64 Effect

| Control | What it does | Range / default |
|---|---|---|
| Effect (header menu) | libultra effect with Nintendo's own settings: Small Room, Big Room (the default of the music player), Echo (179 ms), Chorus or Flange. The effect returns in mono, as on the console. | None / Small Room / Big Room / Echo / Chorus / Flange; None |
| Mix | How much of each voice goes to the effect (equal-power dry/wet as libultra's fxMix). | 0-127; 40 |
| DAC | Hold: each AI sample is held until the next, images included (non-oversampling DAC). Smooth: a low-pass resampler removes them (cleaner than the console). | Hold / Smooth; Hold |

## Playing it

- 16 voices. A repeated note reuses its voice; otherwise the oldest free voice, else the oldest one.
- **Range:** the resampler ratio (note frequency / root frequency) × Src Rate / Out Rate is capped at 1.99996 (libultra
  `MAX_RATIO`): a sample can be read at most about twice as fast as the output rate. Notes above that limit stay at the
  limit pitch, as on the console. A high Src Rate with a low Out Rate leaves the least room above the root.
- **Your own sample:**
  1. Switch to the Synth engine, open the Sample tab, press Edit... and Load a file (WAV, AIFF, FLAC, OGG, .sf2, .brr or
     .spc; for banks a menu lets you pick the item).
  2. Set Start, Length, Loop and Root in the Sample panel.
  3. Switch back to N64 and set Source = User Sample. Src Rate and VADPCM apply to it.
  - The region is resampled to Src Rate and limited to 5 s.
- **Recipe, Big Room pad:** Source = Choir, Attack 40 ms, Release 700 ms, Effect = Big Room, Mix 60 (the factory preset
  N64 Big Room Choir).

## Faithful details

- **VADPCM:** 9-byte frames = 16 samples (scale + predictor index, 16 nibbles), order-2 predictor with an 8×2 codebook
  (Q11) and the frame residual sum (`adpcm_compute_residuals`). The encoder is KoniSynth's own: 4 predictors (no
  prediction, global LPC and 2 k-means centres) and closed-loop scale search.
- **RSP resampler:** 4 taps × 64 phases (the microcode's `RESAMPLE_LUT`), Q16.16 pitch, maximum ratio 1.99996.
- **Envelope:** libultra exponential volume ramps (env.c, `_getRate`: (target/current)^(1/n), minimum 1/32767).
- **Panning and effect send:** libultra's `eqpower[128]` table.
- **Effects (drvrnew.c, reverb.c):** Small Room, Big Room, Echo, Chorus and Flange with their exact parameters: a delay
  line with sections (input, output, feedback, feed-forward, gain, chorus, 1-pole low-pass). Effect input is
  0.707·(L+R) and the effect output is mono (copied from R to L).
- **Output** at the AI rate (22.05 / 32 / 44.1 kHz), then resampled to the host rate.

Optional "nicer" settings, all off by default:

- DAC = Smooth (default Hold).
- VADPCM off (raw 16-bit samples) exists for comparison.

## Limitations

- 16 voices.
- User samples are limited to 5 s at the chosen Src Rate.
- The VADPCM encoder is KoniSynth's own, not Nintendo's tool; the decoder follows the microcode.
- The effect return is mono, as on the console.
- Velocity is KoniSynth's driver behaviour.
