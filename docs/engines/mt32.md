# Roland MT-32

The Roland MT-32 engine emulates the Roland MT-32 (1987) and the CM-32L / LAPC-I: LA synthesis (short PCM
partials combined with synthesized partials), the unit's digital reverb and its 20-character LCD. It runs Munt mt32emu
2.8.3 (LGPL-2.1+) unmodified, with the unit's own bugs: the first-generation DAC overflow, and reverb and LCD messages as
the ROM defines them. The output uses Munt's ACCURATE analog mode (the unit's output filter, 48 kHz), converted to the
host rate. Use it for late-80s / early-90s PC game music written for the MT-32, and for its preset sounds.

## What you need

**The Roland ROMs, which you must supply.** The control ROM and the PCM ROM are copyrighted by Roland and are not
included: you must own them.

1. Put the ROM files in `Documents/KoniSynth/ROMs/MT-32` (the default folder), or press **ROMs... > Choose ROM folder...**
   and pick another folder. The choice is global for all KoniSynth instances.
2. KoniSynth scans the folder and its subfolders. Files are recognised by size and SHA-1 (Munt's ROM list), not by name.
   Split halves (L/H) and interleaved pairs (A/B) are merged automatically.
3. The section header shows `LCD  <text>` once a ROM pair is loaded, or `no ROMs: see ROMs...` if not.

Recognised models (from the control ROMs the code accepts):

| Model setting | Control ROMs, in order of preference | PCM ROM needed |
|---|---|---|
| MT-32 | v1.07, v1.06, v1.05, v1.04, BlueRidge, then v2.07, v2.06, v2.04, v2.03 | MT-32 PCM |
| CM-32L | CM-32L/LAPC-I v1.02, v1.00, CM-32LN v1.00 | CM-32L/CM-64/LAPC-I PCM |

The MT-32 setting prefers a first-generation (v1.x) control ROM, the one most late-80s PC games were written for. If only
the other model's ROMs are present, that model is used and the status says "(the other model was not found)".

**ROMs... menu:**

| Item | What it does |
|---|---|
| (status line) | Result of the last scan: the ROMs in use, or what is missing. |
| Choose ROM folder... | Select the folder with your ROMs. |
| Open ROM folder | Opens the current folder (created if missing). |
| Rescan | Searches the folder again. |

The ROMs are loaded only while the MT-32 engine is selected, and again when Model or the host sample rate changes.

## Controls

One section, **Roland MT-32**.

| Control | What it does | Range / default |
|---|---|---|
| Model (header menu) | Which Roland ROM set to use from your folder: MT-32 (first-generation control ROM preferred) or CM-32L (more sound effects, the later DAC). Falls back to the other if only that one is present. | MT-32 / CM-32L; MT-32 |
| Multi | MIDI channels as they come instead of the keyboard routing, for MT-32 .mid files (parts on channels 2-9, rhythm on 10). SysEx always passes. | off |
| ROMs... (header button) | ROM folder menu (see above). | |
| Options... (header button) | MT-32 Options dialog (see below). | |
| Keys | What the keyboard plays. Part 1: MIDI channel 2 of the MT-32 with Program. Rhythm: channel 10, the drum kit. Dimmed with Multi on. | Part 1 / Rhythm; Part 1 |
| Program | Patch of Part 1 (the MT-32 preset bank). The LCD shows its name. Dimmed with Multi on or Keys = Rhythm. | 1-128; 1 |
| Reverb | The MT-32's own digital reverb (room, hall, plate, tap delay), as set by the patch or by SysEx. | on |

**MT-32 Options dialog (Options...).** Optional Munt beautifications, all off by default: the real unit as it is.

| Control | What it does | Range / default |
|---|---|---|
| Reverb | Same parameter as the panel's Reverb. | on |
| DAC | How the LA32 output reaches the DAC. Auto: as the unit does (Gen 1 for MT-32 v1.x, with the digital overflow distortion on loud notes; Gen 2 for later units). Nice: double volume, clean clipping. Pure: the LA32 bits as they are, half volume. Gen 1 / Gen 2 force one generation. | Auto / Nice / Pure / Gen 1 / Gen 2; Auto |
| Amp Ramp | Off = as the real unit: amp ramps may jump to their target (small clicks). On: always gradual. | off |
| Panning | Off = as the real unit: the LA32 only gets 3-bit panning (no exact centre for a single partial). On: 4-bit, smoother. | off |
| Partial Mixing | Off = as the real unit: partials may mix in counter-phase and cancel out. On: always in phase. | off |

## Playing it

- **Part 1 (default):** every incoming note is sent to MT-32 channel 2. Program changes from MIDI are ignored; the
  Program knob sets the patch.
- **Rhythm:** every incoming note goes to MT-32 channel 10, the drum kit.
- **Multi:** messages keep their own MIDI channel, so a full MT-32 arrangement plays (parts on 2-9, rhythm on 10).
  Keys and Program are not used. Recipe for an MT-32 .mid file:
  1. Select the MT-32 engine and check that the header shows the LCD text.
  2. Turn **Multi** on.
  3. In the transport, use the "..." menu > Import MIDI File... and press play.
- **SysEx** from the live MIDI input and from imported .mid files always reaches the unit, in every mode (custom
  patches and LCD messages).
- **LCD:** the header shows the unit's 20-character display, refreshed about 10 times per second.
- When the engine is reset, KoniSynth sends All Notes Off and sustain pedal up on all 16 channels.
- If KoniSynth's global MIDI Input Channel is set to one channel, live channel messages on other channels are dropped:
  keep it at Omni for Multi from an external sequencer. Imported .mid files are injected after that filter.

## Faithful details

- **Munt unmodified**, so the emulated unit's bugs stay: first-generation DAC overflow, reverb and LCD behaviour per ROM.
- **DAC Auto** picks Gen 1 for v1.x / BlueRidge control ROMs (the famous digital overflow distortion on loud notes) and
  Gen 2 for later ones.
- **Nice Amp Ramp off:** Munt enables it by default ("we prefer the quality improvement over the emulation accuracy",
  Munt Synth.h); KoniSynth starts with it off, like the unit. Nice Panning and Nice Partial Mixing are off in Munt too.
- **MIDI cable delay** emulation (Munt `DELAY_SHORT_MESSAGES_ONLY`) is kept.
- **Analog output:** Munt ACCURATE mode, the unit's output filter at 48 kHz.

Optional "nicer" settings, all off by default (Options...): DAC = Nice (or Pure), Amp Ramp, Panning, Partial Mixing.

## Limitations

- No sound without your own Roland ROMs; none are included.
- The take recorder does not capture SysEx: a take exported as MIDI has no SysEx (imported .mid files do play theirs).
- Program changes are ignored in Part 1 mode (the Program knob decides).
- Opening the ROMs takes some tens of milliseconds (tables and ROM loading); it is done off the audio thread.
